# Stackminute visual direction

## Reference

Adapted from the user's Raycast design-system reference: dark, precise, monochromatic developer tooling, restrained coral accents, expressive typography, zero letter spacing, and an editorial, full-bleed visual. This is an original identity, not a copy of Raycast.

## Foundation

- A deep near-black canvas, bright soft-white text, clearly differentiated graphite surfaces, quiet cool-neutral dividers, and a small vermilion accent.
- Inter for product headings and prose; JetBrains Mono for metered amounts, buttons, framework details, and data.
- Tight, left-aligned headings; readable contrast; deliberate breathing room; a 1,200 px content maximum; and a crisp 6 px control radius.
- Make the running-from-zero hardware illustration and real ecosystem marks the visual evidence. Keep the first screen direct and the rate sheet readable.
- Keep typography, colors, and shared component styling in the global design tokens. Use semantic component classes.

## Interface behavior

- The main page is a scannable, single-page company overview with named on-page destinations.
- Present GitHub builds, automatic scaling, stopping at zero traffic, and SQLite pricing clearly without implying a working checkout or actual app deployment has been connected to this brochure.
- Keep fictional example prices editable in root `pricing.toml`; display the exact free allowances separately from sample paid rates.
- Use accessible brand and framework names with their original marks.
